# CalSync

Menlo Security Browser service를 통해 접속하는 사용자를 대상으로, 지정된 Google Calendar의 일정 조회와 신규 일정 생성·기존 일정 삭제 **요청**을 제공하고 향후 JSON 파일 기반 데스크톱 자동 동기화를 지원하기 위한 프로젝트입니다.

> 현재 상태: 기획 단계. 실제 Google Calendar 연동 및 Menlo 환경의 자동 통신은 아직 구현되거나 검증되지 않았습니다.

## 문서

- [프로젝트 개발 계획서](docs/PROJECT_PLAN.md)

## 기본 원칙

- Google Calendar 조회와 **변경 요청**, 실제 일정 반영을 분리합니다.
- 변경은 기본적으로 관리자 승인 후 실행합니다.
- 접속자에게 Google 인증 비밀을 직접 제공하지 않습니다.
- 데스크톱 클라이언트의 API 통신은 조직이 승인한 네트워크 경로에서만 수행합니다.
- JSON 입력 포맷은 추후 제공될 실제 데이터 샘플에 따라 어댑터로 구현합니다.
- 파일 누락 또는 JSON 오류를 무조건적인 일정 삭제로 해석하지 않습니다.

## 단계

1. Menlo·Google Calendar·에이전트 통신 경로 검증
2. 캘린더 조회 웹 MVP
3. 신규 일정 생성 및 삭제 요청/승인 흐름
4. JSON 파일 감시용 데스크톱 에이전트 시제품
5. 실제 JSON 스키마 연동
6. 보안·안정화 및 배포
