CalSync

캘린더 조회

서버가 지정한 한 개의 Google Calendar만 조회합니다. 삭제 요청은 관리자가 승인하기 전까지 실제 일정에 반영되지 않습니다.

일정 직접 입력

기존 Menlo 브라우저 폼 입력 방식과 호환되는 1건 등록 요청입니다.

JSON 일괄 생성 / 삭제 요청

클라이언트가 준비한 JSON 이벤트 배열, 단일 이벤트 객체 또는 {"events":[...]} 형태를 붙여넣으세요. 전송되는 이벤트 내용은 subject/startTime/endTime/chair/location만 사용합니다. 한 번에 최대 100개입니다.

Menlo에서 클립보드가 차단되어 있다면 위의 직접 입력을 이용하세요. 등록은 기본적으로 관리자 승인 이후 실행됩니다.

요청 및 처리 현황

Windows 클라이언트 동기화 영수증

요청의 처리 상태를 확인해 Windows 프로그램에 붙여넣으세요. SUCCEEDED 결과가 확인되어야 Windows 클라이언트가 실제 반영으로 기록합니다.
